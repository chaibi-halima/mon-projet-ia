## [1.0.0] - 2026-06-17

### Ajouté
* **Symfony AI Platform** : Intégration du LLM local (Ollama/Llama 3.2) avec gestion asynchrone via Messenger.
* **Architecture GraphQL** : Mise en place d'Apollo Client pour une communication API typée.
* **Statistiques** : Module de suivi de l'activité application.
* **Gestion des médias** : Support des images associées aux articles.
* **Paramètres IA** : Contrôle du ton et de la longueur pour la génération de contenu.
* **Pagination** : Navigation fluide pour les listes de données.
* **UX/UI** : Recherche, filtres avancés et amélioration du design avec Ant Design.
